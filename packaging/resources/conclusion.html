Catacomb is installed

Open Logic Pro or GarageBand and add it to a Software Instrument track: AU Instruments → Catacomb → Catacomb.

If Logic was open during the install, quit and reopen it so it loads this version — the version number shows at the top of the panel's Sequencer section.

If Catacomb doesn't appear, open Logic's Plug-in Manager (Logic Pro → Settings → Plug-in Manager) and choose Reset & Rescan Selection on Catacomb.
